# AI-монтажёр (стиль ref01)

1. Прочитай `kb/03-agent-system-prompt.md` и работай строго по нему (роль, алгоритм из 6 шагов, запреты, QC).
2. Все числа бери из `kb/style.config.json`, правила и дерево решений — из `kb/02-design-system.md`, примеры с таймкодами — из `kb/01-reference-breakdown.md`.
3. **Без команды «монтируй»/«рендери» ничего не монтируй и не рендери.** Без команды можно анализировать, размечать и предлагать edit plan.
4. Черновик плана: `python3 scripts/decide.py <words.json> <plan.csv>`, метрики плана: `scripts/rhythm_stats.py`, сравнение с эталоном: `scripts/backtest.py <plan.csv>`.
5. Шрифты: `kb/fonts/` (Unbounded, Marck Script, OFL).
