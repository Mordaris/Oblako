## 8. Звук и цвет

### 8.1. Музыка и громкость [И]

| | A | B | C |
|---|---|---|---|
| Музыка | Сплошная бит-подложка ~140 BPM, плотный саб-бас. **Входит на первом смысловом слове хука** (0,94 с; до этого только голос) | Подложка с первого кадра, на 12–20 dB тише голоса | Тихая подложка |
| Интегральная громкость | −23,6 LUFS | −9,8 LUFS (очень громко) | −13,4 LUFS |
| Склейки на бит | Нет | Нет | Нет |

**Рекомендация для вашего монтажа [Р]:**
- итог −14 LUFS, true peak ≤ −1 dBTP (YouTube приглушает всё громче);
- музыка без вокала, её средние частоты на 18–22 dB ниже голоса;
- **стоп музыки на 0,3–2 с** перед сменой регистра (вход в ч/б, заставка главы) — пауза как акцент.

### 8.3. Цвет несёт смысл

| Цвет | Значение | Где |
|---|---|---|
| Зелёный #20D44A / #36C43A | деньги, бюджет, целевая потребность, рост | A |
| Жёлтый #ECE227 (A), маркер #E09A01 (C), плашка #FEDB00 (B) | **выделение главного** (объект, ключевое слово, главная цифра) | A, B, C |
| Красный #EF0004 / #FF6258 / фон #B23219 | только **боль, ошибка, долг, опасность** | A, B |
| Оранжевый ≈#FF6A1F / #F7AB19 | **собственный продукт** (A) / заставка главы (B) | A, B |
| Бирюза #3BC5C5 | нейтральная инфографика (люди, компании, графики) | A |
| Ч/б, приглушённые цвета | критика, проблема | A |
| Пастельный градиент #87D1F0 → #92FAF8 → #87FBE3 | навигация, разделы | C |
| Фоны сцен | серая студия #A7A7A7, тёмная сетка #101010, тёмный синий #070C14, светлый UI #DDDDDD | A / A / B / C |

**Правила:**
- в кадре со спикером максимум **2 акцентных цвета** (белый + один акцент);
- один цвет — одно значение на весь ролик (L26).

### 9.3. Тайминг: формулы
`w` — время начала слова-триггера.

| Событие | Время |
|---|---|
| Склейка, врезка | `w − 1…3 кадра` |
| Световой переход | склейка внутри перехода после 4-го кадра; склейка = `w − 2 кадра` |
| Субтитр (A) | `w − 3 кадра` |
| Строка титра | `w − 3 кадра` |
| Рукописное слово | `w − 5 кадров` |
| Иконка | `w − 5…13 кадров` |
| Картинка в окне (PIP) | `w − 12…27 кадров` |
| Карточка / полноэкранный сток | A, B: `w − 14…17 кадров`; C: `w … w + 10 кадров` |
| Число (стикер, маркер, титр с числом) | `w … w + 5 кадров` — **никогда раньше** |
| Наезд | старт `w − 4…12 кадров` (типично 6) |
| Прямая речь по словам | каждое слово `w − 0…3 кадра` |
| Подсветка строки таблицы | `w + ~30 кадров` (после слова — «найди в таблице») |

## 10. Лимиты нагрузки («дорого, а не перегружено»)

| Параметр | Значение |
|---|---|
| Визуальное событие | в среднем раз в 1,7–2,6 с |
| Статика спикера | ≤ 5,3 с; обращение и оффер ≤ 7,5 с |
| Доля графики | 30–50% |
| Длительность сцены | 1,2–8,2 с, внутри новый элемент ≤ 2,5 с |
| Хук (первые 30 с) | минимальная средняя длина плана в ролике (A ≤ 3,2 с; B ≤ 2 с; C ≤ 1,5 с) |
| Переходы (не врезки) | не чаще раза в 2,3 с |
| Наезды | не чаще раза в 7 с, пик ≤ 2 с |
| Одновременно поверх спикера | 1 титр (≤ 3 строки) **или** ≤ 4 иконки; максимум титр + 2 иконки |
| Цвета в кадре спикера | ≤ 2 акцентных |
| Рукописных слов в титре | 1 |
| Вход текста | 3–7 кадров; движение камеры и крупных объектов — 12–35 кадров |
| Субтитры вместе с титром | никогда |

## 11. Запреты (что делает монтаж дешёвым)

**Монтаж и ритм:**
- Монтаж или рендер без команды пользователя.
- Склейка по биту вместо речи; склейка после начала слова.
- Число на экране раньше, чем его произнесли.

**Камера:**
- Крупности вне выбранного уровня (например, 110%, 115%, 125% вперемешку).
- Ken Burns «на всякий случай»; наезд дальше 140%.

**Переходы:**
- Переход без смысловой функции.
- Пресеты: spin, page curl, star wipe, «куб».
- Один и тот же leak на каждой склейке.

**Текст и цвет:**
- Анимация текста дольше 7 кадров на вход; bounce или elastic у текста (перелёт допустим только у иконок, ≤ 8%).
- Текст или иконки на лице; текст ниже y = 850 px (кроме субтитров) и правее x = 1700 px.
- Субтитры фразами по 5–7 слов; разноцветные субтитры.
- Красный вне боли и ошибки; цвет собственного продукта — для чужого.

**Звук:**
- Whoosh на каждой склейке.
- Музыка с вокалом под речью.

**Графика:**
- Lens flare, постоянная тряска, VHS-фильтр или виньетка на весь ролик.
- Дождь из эмодзи.
- Сток без цветовой обработки, с водяными знаками.
- Графика на выводе и оффере (L22).
- Две графические системы в одном ролике.

## 12. Чек-лист качества (QC)

- [ ] Каждый переход и оверлей имеет смысловую функцию из §9.2.
- [ ] Тайминги по §9.3: склейки за 1–3 кадра до слова, числа не раньше слова.
- [ ] Лимиты §10 выполнены; хук — самый плотный участок; после плотных блоков — отдых.
- [ ] Перечисления от трёх пунктов визуализированы накоплением; факты подтверждены скриншотом с выделением; структура объявлена.
- [ ] Одна графическая система: одна шрифтовая пара, один цвет выделения, 2–3 типа фона.
- [ ] Выводы и оффер — лицом, без графики.
- [ ] Звук: −14 LUFS, true peak ≤ −1 dBTP, без щелчков на склейках (кроссфейд аудио 1–2 кадра).
