# Модуль 1. Посекундный разбор референса `reference/ref01.mp4`

Экспертный YouTube-ролик (тема: лидогенерация из Telegram-чатов), 121,4 с, 1280×720, 29,97 fps.
Спикер за столом, одна статичная камера; все «планы» спикера — цифровые кропы одного исходника.

**Обозначения**
- `f` — номер кадра при 29,97 fps; 1 кадр = 33,4 мс.
- **Масштаб** — цифровой зум относительно общего плана (1,00 = исходный кадр). Измерен скриптом `scripts/zoom_track.py`, кривые подобраны `scripts/fit_easing.py`.
- **Ур.** — уверенность: **И** — измерено скриптом; **Г** — видно на покадровых листах (±1 кадр); **О** — оценка/гипотеза.
- Пиксели даны для 1280×720 (для 1080p ×1,5).
- Время слов — из `analysis/transcript.json` (GigaAM, шаг ~40 мс).

**Ограничение по звуку.** SFX на переходах измерением не подтверждаются. Речь идёт без пауз и маскирует короткие звуки. Корреляция спектрограмм одинаковых переходов не выше случайной (`ring` 0,23–0,33 при случайных 0,34±0,1). Где в колонке SFX стоит «вероятно», это короткий широкополосный всплеск до 15 кГц в момент склейки, не совпадающий с согласным звуком речи.

**Музыка (И).**
- Бит 140 BPM (период 0,43 с; цикл паттерна саба 6,86 с = 4 такта), с плотным саб-басом.
- Энергия <80 Гц: −26,7 dBFS против −24,3 dBFS у полосы голоса 150–4000 Гц.
- До 0,94 с музыки нет (<80 Гц: −53,9 dBFS); музыка входит на первом смысловом слове хука «топливо» (0,92 с).
- Громкость ролика: −23,6 LUFS integrated, пик −4,3 dBFS.

**Цикл смены планов на спикере** (И)
- Уровни масштаба только два: **1,00** (общий) и **1,20** (жёсткий punch) + плавный наезд до **1,28–1,29**.
- Последовательность на длинных отрезках: 1,00 → (наезд к 1,28 на акценте) → склейка или отъезд к 1,00 → punch 1,20 на новом тезисе → 1,00.
